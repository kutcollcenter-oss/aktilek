# Сайт агентства недвижимости YURTA INVEST

Сайт агентства на своём домене: каталог с подбором по взносу и платежу в месяц, калькулятор рассрочки,
наличные / коммерция / участки, срок сдачи, новости «Скоро», услуги и призыв «Продать квартиру»,
команда специалистов (у каждого своя кнопка WhatsApp), вакансии, карты 2ГИС и Google, заявки в WhatsApp,
русская и кыргызская версии, аналитика в кабинете.

Node.js + Express, обычный JavaScript на страницах. Данные — `data/db.json`, аналитика — `data/events/*.jsonl`, фото — `uploads/`.
**База и фото в GitHub не отправляются** (они в `.gitignore`) — живут только на сервере и в копиях.

## Адреса

| Адрес | Что это |
|---|---|
| `/` | Сайт для клиентов |
| `/kvartira/<id>` | Страница квартиры |
| `/privacy` | Политика конфиденциальности |
| `/admin` | Кабинет: квартиры, профиль (тексты, услуги, команда, вакансии), аналитика — один вход |
| `/sitemap.xml`, `/robots.txt` | Для Google и Яндекса |

## Что меняется в кабинете → «Профиль»

- **Агентство:** название, подпись, фото первого экрана, тексты первого экрана и «О нас», цифры доверия, логотип.
- **Услуги:** список услуг (первая строка — название, дальше описание; услуги разделяются пустой строкой) и призыв «Продать квартиру» с кнопкой WhatsApp.
- **Команда:** до 12 специалистов — фото, имя, должность, свой WhatsApp (пусто — заявка придёт на номер агентства).
- **Вакансии:** первая строка — должность, дальше условия; у каждой кнопка «Хочу у вас работать».
- **Новости «Скоро», отзывы, вопросы и ответы, шаги рассрочки, документы.**
- **Кыргызская версия:** у каждого текста есть поле «по-кыргызски»; пустое — показывается русский текст.

Пустой блок на сайте не показывается.

## Запуск на компьютере

```bash
npm install
npm start
```

Сайт: http://localhost:3010 , кабинет: http://localhost:3010/admin (порт можно сменить: `PORT=3011`).

Если базы ещё нет, при первом запуске создаётся сайт с текстами YURTA INVEST без квартир; логин `yurta`, пароль печатается в консоли.
Для проверки с демо-квартирами: `node lib/seed.js --demo --force` (перед заменой — копия в `data/backups/`).

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `PORT` | Порт (по умолчанию 3010; на сервере 3000 за nginx) |
| `HOST` | На сервере `127.0.0.1` — сайт доступен только через nginx |
| `ADMIN_LOGIN`, `ADMIN_PASSWORD` | Логин и пароль для самой первой базы |

Забыт пароль — `node scripts/set-password.js` (при остановленном сайте), см. [deploy/README.md](deploy/README.md).

## Защита

Защитные заголовки (нельзя встроить сайт в чужую страницу и т. п.), пароль хранится только как хэш,
после 10 неверных паролей подряд вход закрыт на 15 минут, задержка при переборе с одного адреса,
nginx на том же сервере — единственный, кому сайт доверяет адрес посетителя (`trust proxy: loopback`).
Ежедневные копии базы — `data/backups/` (30 дней).
